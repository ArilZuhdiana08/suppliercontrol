┌─────────────────────────────────────────────────────────────────────────────┐
│                         HOW FILES INTERACT                                  │
└─────────────────────────────────────────────────────────────────────────────┘

1️⃣  User opens index.html
   └─ Browser loads TensorFlow libraries (async)
   └─ Browser loads config.js
   └─ Browser loads camera.js
   └─ Browser loads form.js

2️⃣  camera.js initializes
   └─ Loads TensorFlow face detection model
   └─ Sets up event listeners
   └─ Ready for user interaction

3️⃣  User takes selfie
   └─ camera.js captures image
   └─ Auto-fills date fields
   └─ Stores in hidden form fields

4️⃣  User submits form
   └─ form.js handles submission
   └─ Reads WAKTU_REFERENSI from config.js
   └─ Calculates arrival status
   └─ Sends to Google Sheets API

5️⃣  Complete
   └─ Form resets
   └─ camera.js resets state
   └─ Ready for next user

└─────────────────────────────────────────────────────────────────────────────┘

📝 To add a new supplier:
   1. Edit: js/config.js
   2. Add:  "PT. NEW_NAME": "08:00" to WAKTU_REFERENSI
   3. Also update: index.html <select> options

⚙️  To change tolerance:
   1. Edit: js/config.js
   2. Change: TOLERANCE_MINUTES = 10 to your value

🔗 To update API endpoint:
   1. Edit: js/config.js
   2. Change: GOOGLE_SHEETS_API URL

🎨 To change colors:
   1. Edit: style.css
   2. Find: #c8102e (red)
   3. Replace: with your color

🐛 To debug issues:
   1. Open: Browser DevTools (F12)
   2. Check: Console for errors
   3. Check: Network tab for API calls
   4. Review: QUICK_GUIDE.js troubleshooting
