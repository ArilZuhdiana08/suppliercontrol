🔧 TECHNICAL IMPLEMENTATION

Layout System:
  CSS Grid: grid-template-columns: 1fr 1fr (desktop)
  Gap: 30px (desktop), 20px (tablet), 15px (mobile)
  Responsive: @media queries for 3 breakpoints

Button Logic:
  submitBtn.disabled = !(selfieConfirmed && supplierValue !== '')
  Triggers: On selfie confirm, supplier select, form reset

Data Auto-fill:
  Source: captureSelfieTime = new Date()
  Targets: day, month, year inputs + verification display
  Format: Day=getDate(), Month=getMonth()+1, Year=getFullYear()

Event Listeners:
  - startCameraBtn.click → startCamera()
  - captureSelfieBtn.click → captureSelfie()
  - useSelfieBtn.click → useSelfie()
  - supplierSelect.change → updateSubmitButtonStatus()
  - submitBtn.click → handleFormSubmit()

Validation Flow:
  Form submit → Check selfie → Check supplier → Validate → Submit → Reset

📊 USER EXPERIENCE FLOW

1. INITIAL STATE (Page Load)
   Camera section visible (left)
   Form section visible (right)
   Status box hidden
   Submit button DISABLED (gray)

2. TAKE SELFIE
   User clicks "Mulai Kamera"
   User aims face at camera
   User clicks "Ambil Selfie" (enabled when face detected)
   Preview appears with "Gunakan" and "Ambil Ulang" options

3. CONFIRM SELFIE
   User clicks "✅ Gunakan"
   → Status box appears (green)
   → Verification time filled: "10:30:45"
   → Date auto-filled: 04, 12, 2025
   → Submit button status depends on supplier

4. SELECT SUPPLIER
   User opens dropdown
   User selects supplier (e.g., "PT. TENMA INDONESIA")
   → Submit button ENABLED (red gradient)

5. SUBMIT FORM
   User clicks "📤 Kirim Data"
   → Validation passes (both checks OK)
   → Data sent to Google Sheets
   → Success alert shown
   → Form resets
   → Ready for next entry
